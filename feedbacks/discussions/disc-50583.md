# #50583 Persistent Scrollbar in Virtual Table

## 现象
antd 虚拟滚动 Table 默认纵向滚动条仅在鼠标悬停表格时显示（hover-only），用户希望滚动条始终可见（persistent），便于发现"下面还有数据"。

## 复现 / 触发条件
- 任意 antd 5.x `<Table virtual />` 即默认行为
- 数据条数超出 `scroll.y` 视区

## 期望 vs 实际
- 期望：提供开关让滚动条常驻可见。
- 实际：只能通过覆盖 `rc-virtual-list` 内部 CSS 实现，无文档化 prop。

## 根因 / 关键讨论
rc-virtual-list 默认实现就是「hover 才显示」，组件没有暴露 `alwaysShowScrollbar` 之类的开关。回复 anreikas 给的 `.ant-table-tbody-virtual-scrollbar { visibility: visible !important; }` 在提问者环境无效，最终提问者亲自试出的有效方案是覆盖 `.rc-virtual-list-scrollbar-thumb { visibility: visible !important; }`（即父容器一直 visible 不够，thumb 自身也要 visible）。

## 对 data-grid 的启示
CSS Grid 重做虚拟表格时，滚动条显隐策略要做成一等公民 prop（`scrollbar.alwaysVisible` 或对应 token），并且务必同时控制「轨道」与「thumb」两层 visibility，不能只改一层——这正是 antd 此 issue 用户踩坑的根因。
