# disc #55717 表格增加列时会上下抖动

## 现象
OP 做了一个「动态增列」的表格：用户点按钮新增一列 + 同时给所有行加对应字段。`scroll={{ x: 'max-content', y: 400 }}` + 自定义 `render`（多层 `<div>` 包装）。列数多时，**每次新增列都会触发表格整体高度的上下抖动**。

OP 用 AI 分析了 rc-table 源码，定位到 `MeasureRow` 机制：列变化时新列宽度测量存在中间态（undefined），导致布局瞬时回退到 `table-layout: auto`，然后又被测量好的宽度重排，产生闪烁。

## 复现 / 触发条件
1. `<Table scroll={{ x: 'max-content', y: 400 }} />`，`columns` 可动态 push 新列。
2. 新列的 column 定义**没有 `width`**。
3. render 返回多层嵌套 div（`cell-wrapper > cell-container > cell-content > cell-inner > cell-text > cell-value`）。
4. 点击按钮 push 一列 + 改 dataSource；MeasureRow 卸载/重挂 → `useLayoutEffect` 重测宽度 → 中间态列宽 undefined → 布局回退到 auto → 高度变化。

## 期望 vs 实际
- **期望**：动态增列时表格高度完全稳定，不抖动。
- **实际**：rc-table 的 `MeasureRow` + `FixedHolder/useColumnWidth` 是「全或无」策略 —— 任何一列 width 是 undefined，整个列宽缓存作废，回退到 auto layout；尤其有 sticky header / 横向滚动时表现更明显。

## 根因 / 关键讨论
- OP 贴出源码关键路径：
  - `Table.tsx#L385-390`：`pureColWidths = colsKeys.map(k => colsWidths.get(k))` —— 新列未测出 → undefined。
  - `FixedHolder/index.tsx#L12-25`：循环里只要 `colWidths[i] === undefined` 就 `return null` 整组作废。
- dosubot 给的 workaround：
  1. **给所有列（或除一列外）指定 `width`** —— 直接绕过 MeasureRow 重测，避免回退到 auto。
  2. 升级到 `rc-table >= 7.52.7`（相关列宽/滚动修复）。
  3. `scroll.x` 设固定值或 `'max-content'`，确保非固定列宽之和不超过 `scroll.x`。
  4. 注意 `minWidth` 只在 `tableLayout="auto"` 生效，`"fixed"` 下被忽略。
- 即便如此，dosubot 也承认这是 rc-table 的架构性问题，没有彻底修复，只能 workaround。

## 对 data-grid 的启示
1. **架构级解药**：data-grid 用 CSS Grid 重做，天然**不走 MeasureRow + table-layout: auto/fixed 二选一** 这条路径 —— 列宽变化时 grid-template-columns 是声明式的，无中间态。这正好正面解决本 discussion 的痛点，可作为差异化卖点。
2. **动态列稳定性回归**：必须补一个 demo「按钮狂点 100 次连续加列」，断言表格高度 delta == 0、无 layout thrashing、FPS 稳定。
3. **新列默认宽度**：data-grid 应规定 column 定义**可以省略 width**（fallback 到 `minmax(min-content, 1fr)` 或 `auto`），但这一 fallback 必须在 grid track 层声明，不引入 reflow 循环 —— 直接规避 rc-table 的全或无策略。
4. **多层包装警告**：OP 的 render 嵌套 6 层 div，本身就是性能反模式。data-grid 文档应警示「render 返回的元素层数尽量浅」，并在 demo 中示范用 CSS Grid sub-grid 替代多层包装。
5. **横向滚动协作**：与 column-width-scrollbar-policy 协同（已有 memory），保证加列时横滚条只增不减、不闪烁。
6. 该问题与 issue #49445（固定表体高度）同源 —— 都是 rc-table 的 table-layout 机制副作用，data-grid 一并解决。
