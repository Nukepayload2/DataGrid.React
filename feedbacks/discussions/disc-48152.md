# #48152 [RFC] Table 支持可伸缩列

## 现象
作者提议 antd Table 内置支持可伸缩列（resizable column），避免用户被迫组合第三方库（如 `react-resizable`）引发的种种问题。

## 复现 / 触发条件
背景痛点：rc-table 用 `<colgroup>` 控制列宽，但原生 colgroup 对 width 有"假宽度"问题——用户设 `columns=[{width:100}, {width:100}]` 在 800px 容器中实际渲染为 `[400px, 400px]`（按比例放大）。这导致与第三方拖拽库配合时获取的 width 不真实，保存 localStorage 后还原失真。

## 期望 vs 实际
- 期望：Table 内置 `columnResizable` API，colgroup 上 style.width 为真实像素值，`onColumnResize` 回调返回真实 px。
- 实际：截至 antd 6.x，官方仍未实现，#56356 已确认官方下掉了 react-resizable 结合 demo。

## 根因 / 关键讨论
RFC 提议的 API：
- `<Table columnResizable={boolean | { showLine?: boolean }} />`
- `onColumnResize({ columnKey, width, columnKeyWidths })`（用户受控保存 widths）。
- `column.resizable: boolean | { minWidth?: number }`。

设计原则：
1. 开启 resizable 时强制 `tableLayout: 'fixed'`（列增大时其它列不应被减宽）。
2. `column.width` 必须为 number（不设给默认值）。
3. 未超容器宽度时缩放：缩小时总宽不变（互补）；放大时总宽跟着变大。
4. `onColumnResizeComplete` 返回 `columnKeyWidths[]`（所有列真实 px），便于 localStorage 持久化。

维护者反馈：
- **crazyair**（Maintainer）："这个可是收费功能(某些库)" —— 暗示 AG Grid 等商业表格把 resizable 当高级功能。
- **MadCcc**（Maintainer）逐条 review：`onResize` → `onColumnResize`（语义化命名）；三参合并对象；"未超出容器宽度时总宽度不变"；`mode` 不需要（用户受控）；`onResizeStart` 暂不做。
- **liixing**：配合 `react-resize` 会导致**头部筛选失效 + columns.title 额外渲染元素出问题**——又一处第三方组合的反例。

投票：👍3 + 🚀1（含 thumbs-up 共 7）。

## 对 data-grid 的启示（★ 本批 RFC 关键）
1. **CSS Grid 单点改 `grid-template-columns` 即可**：antd 病根是 `<colgroup>` 的假宽度。data-grid 用 CSS Grid，`grid-template-columns: 100px 100px` 就是真实像素，不存在 colgroup 假宽度问题——**RFC 描述的核心痛点在 data-grid 中结构性消失**。
2. **官方 API 设计可直接借鉴**：MadCcc review 后的命名规范值得采纳：`columnResizable`（顶层 prop）、`onColumnResize`（语义化）、不引入 `mode`（用户受控）、`onColumnResizeStart` 暂不做。data-grid 应提供同形态 API。
3. **持久化是核心需求**：作者强调"必须保存真实 px"。data-grid 的 `onColumnResizeComplete` 应返回完整 `columnKeyWidths[]` 而非单列 width，便于用户直接 JSON.stringify 入 localStorage。
4. **未超容器宽度时缩放规则**：缩小时总宽互补（A-100 → B+100），放大时总宽跟着变大——这是用户期望的直觉行为，data-grid 应实现此规则（可借鉴 react-resizable-panels 的 group 逻辑）。
5. **收费功能差异化**：crazyair 提到 AG Grid 等把它当收费/高级功能。data-grid 内置免费提供是明显卖点。
6. **#56356 印证 RFC 未落地**：此 RFC 2024-03 提出到 2026-07 仍未实现，antd 反而决定下掉 demo（#56356）。data-grid 若提供高质量 resizable，将填补社区空白。
