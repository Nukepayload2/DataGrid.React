# disc #54739 v5.21.5 表格隐藏滚动条失败

## 现象
OP 升级到 antd v5.21.5 后，发现常规的隐藏滚动条 CSS（`overflow: hidden` / `::-webkit-scrollbar { display: none }`）在 Table 上**不生效**。固定表头 demo（Codesandbox 链接）的滚动条无法隐藏。

## 复现 / 触发条件
- antd 5.21.5（及以上），`<Table scroll={{ y: ... }} />` 固定表头 + sticky 横向滚动。
- 在表格容器外层加 `.hide-scrollbar { scrollbar-width: none } ::-webkit-scrollbar { display: none }`。
- 滚动条依旧显示。

## 期望 vs 实际
- **期望**：CSS 隐藏滚动条能生效（与旧版本一致）。
- **实际**：v5.21.5 引入了「sticky / fake 滚动条」自定义元素（`.ant-table-sticky-scroll`、`.ant-table-sticky-scroll-bar`），由 CSS-in-JS 强制注入颜色/高度/圆角，简单外部 CSS 无法覆盖。

## 根因 / 关键讨论
- dosubot 解释：新版 Table 不再用原生滚动条做 sticky 横向滚动，而是渲染了一组**自定义的"假"滚动条元素**，所以 `::-webkit-scrollbar` 这种伪元素方案只能影响原生条，不能影响假条。
- Workaround（另一位回复者给出 + 修改前后截图）：
  ```css
  .hide-scrollbar {
    -ms-overflow-style: none;  /* IE and old Edge */
    scrollbar-width: none;     /* Firefox */
  }
  .hide-scrollbar::-webkit-scrollbar {
    width: 0;
    height: 0;
    display: none;             /* Chrome, Safari, Edge */
  }
  ```
  关键是把 class 加到**内部那几个具体滚动容器**（`.ant-table-body` / `.ant-table-content`）上，而不是外层 wrapper；同时如果开了 sticky 横向滚动，要对 `.ant-table-sticky-scroll` 单独 `display: none !important`。
- discussion 仅 2 人参与，无维护者介入。

## 对 data-grid 的启示
1. **与 column-width-scrollbar-policy 直接呼应**：本仓 memory 明确「横滚条永不占布局，非 sticky 一律 FloatingScrollBar(horizontal)，3 处原生条来源全消除」—— 正是本 discussion 反映的痛点；data-grid 应保证用户**无需写 CSS** 就能切换 `scrollbar: 'none' | 'native' | 'floating'`。
2. **API 抽象**：提供 `scrollbar.visibility: 'visible' | 'hidden' | 'hover'` / `scrollbar.variant: 'native' | 'floating'`，避免用户去对 `.ant-table-sticky-scroll` 这种**内部实现细节 class** 打 `!important`。
3. **回归用例**：在 Chrome / Firefox / Safari / Edge 四种浏览器下断言 `scrollbar: 'hidden'` 真的把横竖两条都隐藏（包括 data-grid 自己的 FloatingScrollBar 也要一并隐藏）。
4. **文档警示**：写一篇「为什么不能用 `::-webkit-scrollbar` 隐藏 antd v5.21+ 表格滚动条」迁移指南，引导用户来 data-grid。
5. 与 issue #56334（组件级关 Popover 动画）同类：都是「antd 把内部实现暴露给用户去 CSS 覆盖」的副作用，data-grid 用清晰的 component-level API 规避。
