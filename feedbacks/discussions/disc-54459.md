# #54459 树形表格，子节点是空数组的时候，如何隐藏展开按钮？

## 现象
（本 discussion 由 Nukepayload2 本人，即 data-grid 作者自己提出，是真实业务痛点。）  
使用 `<Table expandable={{ childrenColumnName: 'items' }}>` 渲染树形数据时，只要某个节点的 `items` 是 `[]` 空数组，Table 依旧渲染展开按钮；点击后里面什么也没有，体验很差。期望：空数组节点不显示展开按钮。

OP 尝试过的方案都不可行：
1. **自定义 expandIcon**——不想改默认图标（影响美观、版本兼容、布局对齐）。
2. **`rowExpandable`**——对树形模式压根不生效，源码里写了"此功能不支持 tree mode"。
3. **修改数据源**（删空数组）——不想动数据源，数据量大时怕低配机性能/内存爆。

## 复现 / 触发条件
- antd（任意当前版本），数据里父节点 `items` 字段取值分别有 `null`、`undefined`、未设置、`[]` 四种情况。
- 只有 `[]`（空数组）会错误显示展开按钮；前三种不显示。
- 最小复现见 discussion 链接里的 TSX 源码。

## 期望 vs 实际
- 期望：`items: []` 与 `items: null / undefined / 缺失` 行为一致，都不显示展开按钮。
- 实际：`items: []` 仍渲染展开按钮。

## 根因 / 关键讨论
Dosu 回复确认：antd Table 在树形模式下，只要检测到 `childrenColumnName` 字段存在（哪怕是空数组）就会渲染展开按钮，这是官方有意为之的设计；`rowExpandable` 在树形模式下不生效。当前**没有内置配置**能在不改数据源、不改图标的前提下隐藏空数组的展开按钮。维护者（未署名）回复："这个最小复现不错 👍"——表示认可，但暂未给出修复计划。

## 对 data-grid 的启示
1. 这条是**第一方业务痛点**（data-grid 作者自己提的），必须优先解决：tree data 下判定"是否有子节点"应使用 `Boolean(record[childrenColumnName]?.length)`，而不是 `childrenColumnName in record`。
2. 提供一等公民 API：`expandable.rowExpandable(record, index) => boolean`——且要**对树形模式生效**（与 antd 不同）。这样用户无需改数据源就能控制是否显示展开按钮。
3. 还要考虑 `null` / `undefined` / 未设置 / `[]` 四种"无子节点"语义的统一：默认行为应是"空数组等同无子节点"；如需区分（例如 `[]` 表示"加载中"，可点开触发懒加载），提供单独的 `showExpandOnEmpty` 开关。
4. 回归用例直接抄本 discussion 的最小复现（4 种 items 取值），确保 data-grid 不会重复踩坑。
