# #53921 virtual + scroll.y 行内元素不居中

## 现象
antd 5.25.3 同时开启 `virtual` 和 `scroll.y` 后，**单元格内行内元素（文字、图标等）不再垂直居中**，全部顶格对齐；关闭虚拟滚动时则正常居中。

## 复现 / 触发条件
- antd 5.25.3 + React 18.3.1 + macOS Sonoma + Chrome 135
- 复现：https://4t9qh9.csb.app/
- Table 同时设置 `virtual` + `scroll={{ y }}`

## 期望 vs 实际
- 期望：开启虚拟滚动后，单元格内容垂直居中表现与未开启时一致（默认 `vertical-align: middle`）。
- 实际：内容全部顶格，需用户手写 CSS 修正。

## 根因 / 关键讨论
- Dosu 分析：虚拟滚动用 rc-virtual-list 替换 `<tbody>`，内部行采用 `display: flex` 渲染，原 table 布局下的 `vertical-align: middle` 失效；flex 布局需要显式 `align-items: center`。
- Workaround（社区）：覆盖 CSS
  ```css
  .ant-table-tbody-virtual .ant-table-row { align-items: center; }
  .ant-table-cell { display: flex; align-items: center; }
  ```
- 无官方修复，无 linked PR。

## 关联图片
- 无（仅 shields.io 徽章）

## 对 data-grid 的启示
data-grid 用 CSS Grid 布局 Table，单元格 `display: grid` 时同样会遇到行内子元素垂直对齐问题。**应在基础样式里显式设定 `align-items: center`（或 cell 内容容器 `place-items: center`）**，避免用户额外写 CSS。虚拟开关绝不能改变对齐行为——同一份 cell 样式必须对虚拟/非虚拟两种模式都成立。
