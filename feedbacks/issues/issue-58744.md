# #58744 【Table】表格嵌套表格，内部表格设置 bordered，缺少上边框

## 现象
antd 6.5.1 下，外层 Table 通过 `expandedRowRender` 渲染了一张嵌套 Table 并设置 `bordered`，结果内层 Table 没有上边框，视觉上塌陷成"无顶"表格。期望外层 `bordered` 时嵌套表格也完整呈现四条边框。

## 复现 / 触发条件
- antd 6.5.1 / React 18 / Chrome 149 / Win10。
- CodePen: https://codepen.io/zjgyb/pen/KwaeOey?editors=0010
- 关键结构：外层 Table → `expandedRowRender` 返回另一张 `<Table bordered />`。

## 期望 vs 实际
- 期望：嵌套 `bordered` Table 存在上边框。
- 实际：上边框被错误地 `border-top: 0` 干掉。

## 根因 / 关键讨论
Dosu 给出了精准根因（`components/table/style/bordered.ts`）：

```ts
[`${componentCls}-cell`]: {
  [`${componentCls}-container:first-child`]: {
    // :first-child to avoid the case when bordered and title is set
    borderTop: 0,
  },
}
```

这条规则本意是"bordered + title 同时出现时去掉重复上边框"，但选择器 `.ant-table-cell .ant-table-container:first-child` 太宽泛——展开行的 `<td>` 自带 `.ant-table-cell`，里面 `bordered` 表格的 `.ant-table-container` 又恰好是 `:first-child`，于是被错误抹掉。建议修复方向是用兄弟选择器精确匹配有 title 的场景：

```ts
[`${componentCls}-title ~ ${componentCls}-container`]: { borderTop: 0 }
```

PR `ant-design#58746` (fix(Table): preserve nested table top border inside custom content) 已挂上。

## 对 data-grid 的启示
1. 边框去重规则不能简单靠 `:first-child`，应基于"前一个兄弟节点是 title"这种语义化条件，避免误伤嵌套场景里同样满足 first-child 的 container。
2. data-grid 在为"bordered + 标题"做去重时，建议用 `data-title-present` 属性或 Grid 命名行 (`grid-template-rows: auto 1fr`) 区分标题行与表体行，而不是依赖 DOM 顺序选择器。
3. 嵌套表格是高频用法（展开行内嵌详情表），样式应专门做一次"嵌套回归"：内层 `bordered` 表格的 4 条边框必须完整。
