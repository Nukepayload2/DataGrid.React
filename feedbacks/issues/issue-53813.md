# #53813 虚拟表格滚动条不能点击

## 现象
开启 antd Table 虚拟滚动后，原生横向滚动条不出现，取而代之的是自定义浮动滚动条；该自定义滚动条只能拖动滑块，无法像原生滚动条那样点击轨道空白处快速跳转定位，用户必须按住 Shift + 滚轮才能横向快速滚动。

## 复现 / 触发条件
- Table 启用 `virtual` + `scroll={{ x, y }}`
- 横向内容超出容器宽度，出现虚拟横向滚动条
- 在滚动条轨道的空白区域点击

## 期望 vs 实际
- 期望：点击轨道空白处可将滑块（页面位置）按原生滚动条的行为跳跃移动，类似原生滚动条的 track click / 箭头按钮。
- 实际：点击空白无反应，只能拖拽 thumb，横向长距离定位体验差。

## 根因 / 关键讨论
- 维护者 petercat-assistant 回复已记录建议，待未来版本评估。
- 社区补充：滚动条常显需求已通过 ConfigProvider 满足，但"轨道点击跳转"行为仍缺失。
- 无 linked PR，无明确实现计划。

## 对 data-grid 的启示
data-grid 自实现横向 `FloatingScrollBar` 时必须支持轨道点击（click on track → 按页跳转）与键盘箭头，行为对齐原生；仅支持拖拽是不够的，长表横向定位体验会显著下降。
