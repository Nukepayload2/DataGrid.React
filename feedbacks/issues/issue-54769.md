# #54769 虚拟表格动态/可变行高滚动位置跳跃

## 现象
antd 5.27.1 虚拟 Table 数据源周期性刷新（每 5 秒），当某一行实际渲染高度变大（例如图片加载完成或内容动态变化）时，**整个表格的 scrollTop 自动下跳**，原本位于顶部的首行被部分遮挡；关闭虚拟滚动则位置稳定。

## 复现 / 触发条件
- antd 5.27.1 + React 18 + macOS Sequoia + Chrome 139
- `virtual` + `scroll.y`，行高可变（含图片/异步内容/展开行）
- 数据源周期刷新或单行高度从初始值增大

## 期望 vs 实际
- 期望：行高变化时维持用户当前可视位置（顶部行不被遮挡、scrollTop 不漂移）。
- 实际：虚拟列表重算可视区首行索引时未补偿已测量到的行高增量，导致 scrollTop 下移、首行半隐。

## 根因 / 关键讨论
- Dosu 确认这是 antd 虚拟滚动的已知限制：rc-virtual-list 仅渲染可视行，行高变化后重新测量 + 重排可见行时未锚定原 scroll 位置。
- 给出的 workaround 均不可靠：避免动态行高 / 关闭虚拟 / 设 `tableLayout="auto"` + 显式列宽——都不能根治。
- 评论中另一用户复现：固定表高 1000px、单元格内 500px 图片，向上滚 50px 时内容明显跳动。
- 无官方修复，无 linked PR。

## 对 data-grid 的启示
动态行高虚拟化是 data-grid 的核心难点。必须采用 react-virtuoso 式的 **AATree/offsetTree 增量高度索引**：测量到的行高变化时，**以"当前可视首行 + 该行在 viewport 内的偏移"为锚点反向修正 scrollTop**，保证视觉位置不变。`gridOptions(min/max 有界 + rowSpan 豁免)` + isScrolling 期间暂停测量是必要的工程约束。data-grid 记忆中已明确这是唯一性能/体验痛点，必须对齐 virtuoso 范式。
