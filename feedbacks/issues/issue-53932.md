# #53932 虚拟表格头部动态插入数据 Y轴偏移

## 现象
antd 5.25.3 虚拟 Table 中，当向数据列表**头部 unshift 新行**时，可视区域内容看起来"向下偏移"——原本看到的第一行被新行顶下去，但 `scrollTop` 未变化，用户视觉体验是列表"跳了一下"。

## 复现 / 触发条件
- antd 5.25.3 + React 18 + macOS Chrome
- 开启 `virtual` + `scroll.y`
- 在已有数据前 `unshift`/`prepend` 新行

## 期望 vs 实际
- 期望：头部插入数据后，可视位置保持稳定（要么停留在原首行，要么按用户预期滚到顶部）。
- 实际：`scrollTop` 数值不变，但 DOM 上方多了一行，可视内容整体下移一行；用户尝试手动修正 `scrollTop` 会引入抖动且无法精确 scroll 到顶。

## 根因 / 关键讨论
- Dosu（助手）分析：rc-virtual-list 用 `scrollTop` + 首行索引定位可视区，头部插入后内部 offset 未自动补偿。
- 作者反馈 workaround 失败：手动调整 `scrollTop` 有视觉抖动、且无法可靠定位。
- 作者澄清关键点："scrollY 是不变的，在上面插入数据看起来会往下移，实际上滚动没有变化"——即根因是虚拟列表未把"插入高度"累加到 `scrollTop` 上。
- 无官方修复，无 linked PR。

## 关联图片
- 无（仅 codesandbox 徽章，非现象截图）

## 对 data-grid 的启示
data-grid 虚拟化必须显式处理"数据前插"语义：在 `setData` diff 中检测前置插入量，**同步将等量像素累加到 `scrollTop`**（或通过 `scrollOffset` 调整可视区起点），保证用户视觉位置不变。react-virtuoso 的 `followOutput`/`firstItemIndex` 是同类问题的成熟范式，值得借鉴。
