# #50965 ProTable ellipsis 清空 render 返回的所有 style

## 现象
ProTable 的 `column.ellipsis: true` 开启后，`render` 返回的元素（如 `<a>` 链接）的 inline `style` 全部被清除，导致链接失去颜色/下划线，看起来像普通文本。

## 复现 / 触发条件
1. 列定义：
   ```
   { title: 'Name', dataIndex: 'name', ellipsis: true,
     render: (text) => <a style={{ color: '#1677ff' }}>{text}</a> }
   ```
2. 表格渲染后，该列显示的 `<a>` 不再有蓝色，下划线消失，等同于纯文本。

## 期望 vs 实际
- **期望**：ellipsis 只截断文本，不破坏 render 返回元素的样式。
- **实际**：ellipsis 包装层把 inline style 丢掉，甚至用户后续手写的 `style={{ color: 'inherit', textDecoration: 'inherit' }}` 也不生效（作者回复确认）。

## 根因 / 关键讨论
- petercat 给的解法（加 inherit 样式）被作者反馈无效。
- 根因推测：rc-table 的 ellipsis 实现走 `getRender props` 时，会用 `React.cloneElement` 或重新构造一个 `<span className="ant-typography-ellipsis">`，把 children 透传但忽略原元素的 props/style；或者 CSS 选择器 `.ant-table-cell-ellipsis a` 把样式覆盖成 inherit。
- 标签 Inactive + unconfirmed，无维护者跟进。

## 关联图片
无（仅 stackblitz 复现链接）。

## 对 data-grid 的启示
1. data-grid 实现 ellipsis 时，应通过 **CSS**（`text-overflow: ellipsis; overflow: hidden; white-space: nowrap`）作用在单元格层，**不要重新包装 render 返回的 ReactNode**——保留原元素、原 props、原 style。
2. 单元测试：ellipsis + render 返回 `<a>` / `<Tag>` / 自定义组件，断言 inline style 与 className 完整保留。
3. data-grid 的 css var kebab 规约天然支持子元素继承 `color: var(--ant-color-primary)` 等令牌，避免被 ellipsis 覆盖。
4. 提供 `column.ellipsis: true | { showTitle: false, tooltip: true }` 等结构化 API，让样式职责清晰分层。
5. 这是 antd 长期未修的渲染陷阱，data-grid 设计上规避即可作为差异化正确性卖点。
