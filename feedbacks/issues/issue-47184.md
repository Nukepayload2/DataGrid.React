# #47184 开启虚拟列表后 summary 无效

## 现象
antd 5.10.3 Table 同时配置 `virtual` 与 `summary` 时，**Summary 内容不显示**；移除 `virtual` 后 summary 正常出现。

## 复现 / 触发条件
- antd 5.10.3 + React 18 + Win10 Chrome（旧版本）
- 复现：https://codepen.io/mldpxnef-the-sasster/pen/wvOPjKM
- Table 设置 `virtual` + `summary`

## 期望 vs 实际
- 期望：虚拟表格也支持非 fixed summary（即随表体滚动的合计行）。
- 实际：非 fixed summary 在虚拟模式下不渲染。

## 根因 / 关键讨论
- 维护者回复（@zombieJ 风格，看 rc-table 源码后）：**"嵌在 virtual 里面的目前不支持"**——即 summary 渲染在虚拟列表的 scroll 容器内部，与 rc-virtual-list 的渲染管线不兼容。
- 官方建议 workaround：使用 `summary` 的 `fixed` 属性把合计行固定在表格外（`fixed="top"`/`"bottom"`），渲染在虚拟列表之外，可绕开该限制。
- 评论后续澄清：升级浏览器版本后 + fixed summary 可正常工作（早期部分浏览器对 sticky 兼容性差导致 fixed summary 也不显示）。
- 结论："虚拟表格下 Summary 只能 fixed"——是设计限制而非 bug。
- Issue 已关闭。

## 对 data-grid 的启示
data-grid 虚拟化时 Summary 必须独立于虚拟行容器——把 summary 行渲染在虚拟滚动区**之外**（作为独立的 `<tfoot>` 或 sticky bottom 区），并支持 `fixed` 模式固定底部。绝不能让 summary 跟着虚拟行一起 diff/裁剪，否则会导致合计行消失或位置错乱。这是虚拟表设计的硬约束。
